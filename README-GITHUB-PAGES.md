# FISHERMANS — Catálogo para clientes

Este pacote contém a versão corrigida do catálogo interativo Fishermans, preservando a identidade visual original em azul-marinho e laranja.

## Publicação no GitHub Pages

1. Extraia o ZIP.
2. Envie o conteúdo extraído para a raiz do repositório, mantendo `index.html` no mesmo nível da pasta `assets`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)`.
5. Aguarde a publicação do endereço do GitHub Pages.

O pacote já inclui `.nojekyll`, o bundle JavaScript, o CSS e a imagem de compartilhamento.

## Miniatura ao enviar o link

O arquivo `fishermans-share-preview-final.jpg` é a imagem usada na prévia do link. O `index.html` contém metadados Open Graph e Twitter apontando para:

`https://edeerickson.github.io/Catalogo/fishermans-share-preview-final.jpg`

Para outro usuário ou outro nome de repositório, ajuste no `index.html` os valores de `canonical`, `og:url`, `og:image`, `og:image:url`, `og:image:secure_url` e `twitter:image` para o endereço publicado correspondente.

O WhatsApp pode manter uma prévia antiga em cache. Depois da publicação, abra o link no navegador, aguarde alguns minutos e envie novamente. Se necessário, envie o endereço com uma pequena variação de consulta, como `?v=2`, apenas para forçar uma nova leitura da prévia.
